## Question

At roughly the same Runmaxing usage intensity, do more verifiable outcomes get finished after changing from session supervision to outcome-and-proof management?

This is a dated personal before/after record, not a controlled model evaluation. Different work, dates, and model versions prevent a causal conclusion.

## Intervention

From 2026-08-06 KST:

1. Define one coherent outcome and its `done_when` condition before substantial work.
2. Decide what evidence will prove completion.
3. Run the work normally without forcing a particular model or task mix.
4. Verify with the relevant test, CI, browser, production URL, or published artifact.
5. Count the outcome only after durable evidence exists.
6. Record human steering and review time when it is known; never estimate missing time as zero.

The append-only ledger stays local. Public reports redact private repository titles, names, and URLs.

## Readout rules

- Report the raw outcome list alongside the count so readers can judge differences in scope.
- Call usage “roughly the same” only if the two seven-day run-rates differ by no more than 10%.
- Report human-active-time efficiency only when its coverage is explicit.
- Disclose the Claude Code and Codex versions used during the period when available.
- Use “during” or “after adopting,” not “caused.”

The intended final claim has this form:

> At a similar Runmaxing run-rate, I finished **B** verified outcomes after adopting an outcome-and-proof loop, compared with **A** in the prior seven days.

If usage intensity or work mix differs materially, publish that difference instead of forcing the sentence.
